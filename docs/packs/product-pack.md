# product-pack

Product-quality workflows for frontend design, image-guided UI direction, kaizen evaluation loops, and implementation delivery through merge-ready PRs.

## Skills

- `frontend-design`
- `ui-imagegen-director`
- `kaizen-loop`
- `implement-to-merge-ready`
- `pr-guardian`

## Commands

- `/frontend-design`
- `/ui-imagegen-director`
- `/kaizen-loop`
- `/implement-to-merge-ready`

Install: `claude /plugin install product-pack@claude-harnesses`
