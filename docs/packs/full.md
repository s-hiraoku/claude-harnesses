# full

Umbrella plugin pulling in every functional pack. Use this when you want the full claude-harnesses experience in one command.

```sh
claude /plugin install full@claude-harnesses
```

## Composes

- safety-pack
- verification-pack
- review-pack
- tdd-pack
- pr-guardian-pack
- long-running-pack
- mcp-pack

If `dependsOn` is not yet resolved by your Claude Code version, install each pack individually (see the per-pack pages).
