# no-slop

Remove AI filler, restatement, vague emphasis, stacked hedges, repetition, and
decorative structure from prose while preserving every source fact,
uncertainty, caveat, reason, required step, and failure condition.

Use it as a modifier alongside another task, to rewrite existing text, or as a
session-wide writing rule. It changes how prose is written, not what work is
performed; use `deslop` for code cleanup.

## Install

```sh
gh skill install s-hiraoku/claude-harnesses no-slop --scope project
```

Also available as `skill-no-slop` from the plugin marketplace.
