# ui-imagegen-director

Use image-generated mockups when they improve frontend visual direction, then implement the selected direction in real code and verify the rendered UI.

## Use When

- The user wants a polished app screen, dashboard, landing page, UI mockup, or visual redesign.
- The product has weak or underspecified visual direction.
- Generated images should guide hierarchy and tone, not replace the implemented UI.

Bundled into `product-pack`.
