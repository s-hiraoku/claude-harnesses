# frontend-design

Design and implement purpose-fit frontend UI with layout, typography, color, accessibility, optional image-generated mockups, and browser verification.

## Use When

- A frontend change depends on visual hierarchy, usability, responsive behavior, or content density.
- The product mode needs to be explicit before styling: operational, editorial, playful, commerce, data-dense, or similar.
- Browser verification is required to catch text overflow, overlap, contrast, target size, or state issues.

Bundled into `product-pack`.
