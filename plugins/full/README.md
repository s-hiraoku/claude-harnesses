# full

Umbrella plugin bundling every skill, slash command, subagent, and hook from all claude-harnesses packs into a single install.

```text
/plugin install full@claude-harnesses
```

Install `full` **or** individual packs/skills, not both — combining them loads the same skills twice under different plugin namespaces.

## Contains

- **Skills** — everything under the repository's `skills/` directory
- **Commands** — every slash command from every pack
- **Agents** — `ci-fixer`, `code-reviewer`, `security-auditor`, `tdd-implementer`, `tdd-refactorer`, `tdd-test-writer`
- **Hooks** — merged from `safety-pack` (PreToolUse guards), `verification-pack` (PostToolUse checks + Stop gate), and `long-running-pack` (SessionStart/SessionEnd context, cost ceiling, large-change gate)

All guard hooks honor `CLAUDE_HARNESSES_DISABLE=1` as a kill switch.

## Generated — do not edit

This directory (everything except this README) is generated by `scripts/sync-marketplace.py` from `skills/` and the sibling packs. Edit the sources, then run:

```sh
python3 scripts/sync-marketplace.py
```

`scripts/verify.sh` fails when this directory drifts from its sources.
